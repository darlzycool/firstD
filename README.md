# FirstD

FirstD is a fictional, non-explicit discovery prototype.

## Live versions

- [Static GitHub Pages demo](https://darlzycool.github.io/firstD/)
- [Backend-enabled AppDeploy app](https://firstd-mcrtlk.v2.appdeploy.ai/)

The static GitHub Pages version remains a demo. The AppDeploy version adds real sign-in, account profiles, and private report history.

## Source

- `firstd-website/` contains the static GitHub Pages version.
- `firstd-appdeploy/` contains the deployed AppDeploy app source, including the backend routes, database logic, authentication integration, and tests.
